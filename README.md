## 使用说明

- C/C++ 练习通常选择单个源文件编译，不要把同一目录的多个 main 一起链接。
- 图书管理练习详见 [图书管理说明](courses/c/book-management/README.md)。
- 毕业生信息管理系统使用 `<conio.h>`，需要支持该接口的 Windows 编译环境。
- 网页实验用浏览器打开；外部资源是否可用取决于对应服务和网络。
- Go 入门代码可在其目录运行 `go run test.go`。
