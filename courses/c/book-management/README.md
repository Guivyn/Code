# 图书管理练习

这组练习围绕同一类图书数据，分别使用数组和单链表实现。每个源文件都是独立程序，适合逐个编译、运行和对照学习。

## 目录

- `array/`：数组版，实现查看、统计、插入、查询、调价、排序和倒序排序。
- `linked-list/`：链表版，实现查看、统计、插入、删除、查找、调价、排序和倒序排序。

## 文件说明

数组版中的 `query.c` 来自原来的 `exercise_delete.c`。它实际实现的是按位置查询和按书名查找，并没有真正删除记录，因此按实际内容命名。

链表版中的 `statistics.c` 是原 `book_linked_statitic.c` 的拼写修正版。

这些程序没有共用头文件或统一构建脚本，编译时选择单个源文件即可。
